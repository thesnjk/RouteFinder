## Two-minute talk track (in person)

1. **Hook (20 s):** “CoPilot-class constraint routing + physics ETA, but dispatch stays on hardware you already own — LAN Bonjour, not a monthly portal.”
2. **Demo (60 s):** Start fleet server → push trip (web or Mac) → phone toast → Find route → Rehearse → show trip brief / walkaround defect card / optional map pin on dispatch.
3. **Ask (20 s):** “Three phones, sixty days, one feedback form. If it wastes your time, we stop. If it helps, desk fee about **£39/mo** for ≤10 trucks with routing API included.”
4. **Close (20 s):** Leave pilot agreement; book install day; get vehicle UUID process agreed.

**May mention:** snapshot pin on dispatch map, read-only partner telematics CSV, optional hosted gateway for remote depot, UK toll **hints**, Android driver app for mixed fleets (pilot still easiest on iPhone).

**Do not promise:** continuous live telematics map platform, TRAVIS booking / paid SNAP APIs, toll tariff tables, remote VU / legal ELD, hosted SaaS billing portal, Android Auto, 24/7 support, CarPlay (unless your entitled build is what you demo).

**If asked about Android:** “Pilots run easiest on iPhone; Android driver app is available for mixed fleets (trip receive + navigation). We can show it if you need Android drivers in the pilot.”

**If asked about Windows office PCs:** “Native dispatch is Mac/iPad today; a LAN web dispatch console is available so the office can push trips from a browser.”
