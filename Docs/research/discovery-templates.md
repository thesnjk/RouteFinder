## Interview guide (minimal)

1. Current nav/dispatch tools and monthly cost (**do not invent competitor prices in notes—date any quoted figure**).
2. Last time a constraint/LEZ/HOS failure cost time or money (behaviour, not opinion).
3. Who buys vs who uses (Sarah vs drivers).
4. Show workflow: push trip → rehearse → break/HOS — what would block adoption?
5. Pilot ask: 60-day / ≤3 phones / £0 → then indicative desk fee—reaction?

## Observation checklist (demo)

- [ ] Same Wi‑Fi or agreed remote path
- [ ] Push trip received on cab
- [ ] Constraint/LEZ/toll advisory visible without overclaim
- [ ] Desk roster/snapshot understood
- [ ] Objection logged (Android/Windows/legal/price)
