## Recruitment / ICP filter (stub)

Use before adding names to [`../pilot-outreach.md`](../pilot-outreach.md). **Do not** copy the account table here.

| Filter | Pass if |
|--------|---------|
| Fleet size | Independent haulage/courier roughly **5–15 trucks** (ICP wedge; ≈2–20 OK to talk) |
| Buyer | Transport manager / owner-operator buyer (“Sarah”-class) — not only a driver unless OO backup track |
| Geography | Norfolk / East Anglia preferred (~45 min for door/coffee demos); northern names = remote email reserves only |
| Workflow | Uses (or needs) constrained routing and/or office→cab trip handoff |
| Exclude | Full telematics/VU replacement shoppers as primary pitch; enterprises needing Samsara-class stack |

CRM stages live on the outreach Doc: Target → Contacted → Replied → Discovery booked → Discovery held → Pilot offered → Pilot agreed → Pilot active → Continuation decision → Customer / Lost. Advance only on dated real actions.

## Interview guide (minimal)

1. Current nav/dispatch tools and monthly cost (**do not invent competitor prices in notes—date any quoted figure**; see [`../competitor-pricing-2026.md`](../competitor-pricing-2026.md)).
2. Last time a constraint/LEZ/HOS failure cost time or money (behaviour, not opinion).
3. Who buys vs who uses (Sarah vs drivers) — personas Doc.
4. Show workflow: push trip → rehearse → break/HOS — what would block adoption?
5. Pilot ask: 60-day / ≤3 phones / £0 → then indicative desk fee—reaction? Label **pilot interest** vs **paid intent** separately.

## Charter decision gate (reminder)

After **≥3** discovery conversations with workflow evidence **and** **≥1** signed/started free pilot **or** a clear refusal pattern → refresh [`validation-scorecard.md`](validation-scorecard.md) and choose **GO / NARROW / PIVOT / STOP** on the charter explicitly (**no silent pivots**). Agent refreshes scorecard only from **dated logged** outreach/synthesis (backlog **B8** / **B15**) — never invent outcomes.

**Prohibit:** fabricated quotes; treating enthusiasm as purchase intent; bulk outreach before message validation.

**Empty-outcome honesty:** Log objections, ghosts, refusals, and empty meeting/outcome columns in [`negative-findings-log.md`](negative-findings-log.md). Empty outreach outcomes ≠ willingness to pay.
